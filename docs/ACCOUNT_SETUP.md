# 平台账号接入完整手册（QQ / 钉钉）

> 目标：把 QQ、钉钉的账号接入「聊天智能分析助手」，实现真实群消息的抓取、提醒与日报。
> 对应系统操作位置：Web 设置页 → 「QQ 账号绑定」/「钉钉账号绑定」。
> ⚠️ 平台控制台界面会不定期改版，菜单名以实际页面为准；以下技术事实（字段名、权限点、协议）均已核对。

---

## 〇、你需要准备的 4 样东西

| 平台 | 要拿到的值 | 数量 |
|------|-----------|------|
| QQ | AppID + AppSecret | 2 |
| 钉钉 | AppKey + AppSecret | 2 |
| 系统 | 管理员账号（已有 admin） | — |

> 监控群 ID（QQ 群 openid / 钉钉 chatId）**可以先不填**（留空 = 监控所有群），跑通后再回来精确筛选。

## 一、QQ 开放平台机器人（官方，推荐）

### 1.1 创建机器人

1. 浏览器打开 **https://q.qq.com**（QQ 开放平台），用 **QQ 扫码登录**；
   - 建议使用专用小号（机器人与个人账号身份绑定）。
2. 首次使用按提示完成**开发者注册/实名**（个人开发者即可）；
3. 找到「**创建应用 / 创建机器人**」→ 选择「**机器人**」类型；
4. 填写：机器人**名称**、**头像**（建议 240×240）、**简介**、服务场景（勾选**群聊**）；
5. 提交创建。创建后进入应用详情页：
   - **开发设置 / 凭证与基础信息** → 记录 **AppID** 与 **AppSecret**；
   - ⚠️ **AppSecret 只在创建时完整显示一次**，立即复制保存（丢失需「重置」生成新的，旧的立即失效）。

### 1.2 配置机器人（关键开关）

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 消息接收模式 | **WebSocket** | 我们的 worker 主动连网关 `wss://api.sgroup.qq.com/websocket/`，**无需公网回调地址**；不要选 HTTP/Webhook |
| 「接收所有消息」/ 全量模式 | **开启** | 对应事件 `GROUP_MESSAGE_CREATE`——开启后群里**每一条消息**（不只 @机器人）都会推送；不开就只能收到 @ 机器人的消息 |
| 发布状态 | 已发布 | 个人机器人 2026-03 起全量开放（每个 QQ 号最多 5 个）；未发布时功能受限 |
| 环境 | 沙箱 / 正式 | 开发期用沙箱 `QQ_ENV=sandbox`，正式用 `QQ_ENV=prod`（正式环境网关：`api.sgroup.qq.com`；沙箱：`sandbox.api.sgroup.qq.com`） |

### 1.3 在系统里绑定

1. 打开 **http://127.0.0.1:8001** → 登录 → **设置** → **QQ 账号绑定**；
2. 填写：**AppID**、**AppSecret**、**环境**（正式/沙箱）；
3. 「监控群 openid」**先留空**；
4. 「启用」选 **启用**；
5. 点 **「测试连接」** → 成功提示「获取到 access_token（xx 字符）」；
6. 点 **「保存并重启」** → 提示配置已保存，QQ worker 自动重启加载。

### 1.4 拉机器人进群并验证

1. 在 QQ 客户端（手机/电脑）搜索机器人名称 → 添加，或由群管理把机器人拉入目标群；
2. 在群里发一条消息（如「测试」）；
3. 打开系统 **「消息」页 → 切到 QQ** → 应能看到刚发的消息（群名显示为 openid 后 8 位）；
4. ✅ 能看见消息 = 全链路通了（机器人入群 → WS 推送 → 入库）。

### 1.5 精确监控：获取群 openid（可选）

留空=全部群。想只监控指定群时，获取完整 openid 的方法：

- **方法 A（推荐，已入库后）**：查本地数据库
  ```
  sqlite3 D:/chat-monitor/data/qq.db "SELECT DISTINCT group_id, group_name FROM messages"
  ```
  `group_id` 列就是完整 openid（`o` 开头长串），多个用英文逗号填入绑定表单后保存重启。
- **方法 B**：QQ 开放平台提供的接口调试（获取群信息，需群主授权）查看 `group_openid`。
- ⚠️ 填错会过滤掉该群消息；不确定就保持留空。

## 二、钉钉企业内部应用（官方）

### 2.1 前提

- 一个**钉钉企业/组织**（学校组织或自建组织均可），你在其中具备**应用开发/管理权限**（或请管理员协助）。

### 2.2 创建应用

1. 打开 **https://open.dingtalk.com** → 用钉钉扫码登录（需企业开发者/管理员身份）；
2. 「**应用开发 → 企业内部开发 → 创建应用**」；
3. 填写应用**名称**、**Logo**、简介 → 创建；
4. 进入应用详情 → 「**凭证与基础信息**」→ 记录 **AppKey** 与 **AppSecret**（⚠️ 同样只显示一次，立即保存）；
5. （可选）「应用功能 → 机器人与消息推送」开启机器人能力——拉消息用 API 即可，机器人非必需。

### 2.3 申请关键权限（必做）

1. 应用详情 → 「**开发配置 → 权限管理**」；
2. 搜索并**申请**以下权限点：
   - **`qyapi_chat_read`**（读取群会话消息）——核心权限，拉取聊天记录必需；
   - `qyapi_chat_base_read`（群基础信息）——建议一并申请；
3. 权限为高级权限时，审批会要求说明用途（按「合理必要」原则描述：内部群聊内容分析），等待管理员/钉钉审核通过；
4. 权限通过后，**群主/管理员**需在目标群内完成**授权**（应用才能读该群消息）。

### 2.4 获取监控群 chatId

- **方法 A（推荐）**：权限获批后，在钉钉开放平台的**接口调试工具**调用「获取群列表」（`chat/list` 或新版对应接口），返回结果中每个群的 `chatid`（形如 `chatxxxxx`）；
- **方法 B**：把机器人拉进目标群后，再调用群列表接口；
- **方法 C**：已有消息入库后查库（同 QQ 方法 A）：
  ```
  sqlite3 D:/chat-monitor/data/dingtalk.db "SELECT DISTINCT group_id, group_name FROM messages"
  ```
- 多个群用英文逗号分隔填入 `DINGTALK_CHAT_IDS`。

### 2.5 在系统里绑定

1. **设置 → 钉钉账号绑定**：填 **AppKey**、**AppSecret**、**监控群 chatId**（可先留空，但钉钉**建议必填**——留空时不会拉任何群）、启用=启用；
2. **「测试连接」** → 成功提示「获取到 accessToken，凭证有效」；
3. **「保存并重启」** → 钉钉 worker 重启；
4. 钉钉 worker 按 `POLL_INTERVAL`（默认 90 秒）轮询 `getChatHistory` 增量拉取；
5. 系统「**消息」页 → 切到钉钉** → 看到消息即成功。

## 三、系统侧操作速查

| 操作 | 位置 |
|------|------|
| 登录 | 登录页（注册新账号 = 普通用户只读；admin = 管理员） |
| 绑定平台 | 设置 → QQ/钉钉 账号绑定（凭证/环境/监控群/启用 + 测试连接 + 保存并重启） |
| 看消息 | 消息页（QQ/钉钉 切换键 + 群筛选 + 关键词搜索） |
| 看提醒 | 提醒页（重要事项 + 执行建议 + 标记已读） |
| 看/生成报告 | 报告页（预览 html / 下载 docx / 总览页手动生成） |
| 改关键词 | 设置 → 重要信息关键词库（保存后自动下发重载） |
| 看保存的文件 | 文件库页（缩略图预览 / 下载 / 平台·分类筛选 / 仅看重要） |
| 文件保存位置 | `data/media/{平台}/{日期}/`（数据库 `files` 表记录元数据与 AI 识别结果） |

> worker 状态：总览页卡片显示「运行中/已停止」。刚保存绑定后需**重启对应 worker**（保存按钮会自动下发 restart，systemd 环境下自动拉起；本地手动 `python main.py qq` 需重启）。

## 五、文件库（媒体自动保存 + AI 识别）

群里的图片/文件会自动**下载保存**并进入「文件库」页：

- **保存**：`data/media/`，图片/文件全部留存；消息里的附件直链自动下载（QQ），钉钉图片/语音走官方 `media/download`；
- **AI 识别**：图片用视觉模型 `qwen-vl-plus` 识别内容，文件按文件名+上下文判断 → 标记 **★ 重要**、打分类标签、生成一句话描述；
- **重要文件提醒**：AI 判定为重要（作业/通知/证件/表格等）→ 自动生成「重要文件」提醒并实时推送；
- **文件库页**：缩略图预览、下载、按平台/分类/仅重要筛选、关键词搜索；管理员可手动「标重要/取消」；
- **表情**：QQ 表情自动转为「[表情]」文本展示。

> ⚠️ 平台差异：QQ 附件直链可完整下载；QQ 富媒体 element、钉钉新版文件（`downloadCode`）需要签名下载接口，当前保留占位（不影响消息入库）。AI 识别为付费调用（`qwen-vl-plus`），可按需在设置页调整。

## 六、常见问题排查

| 现象 | 排查方向 |
|------|---------|
| 「测试连接」失败 | ① AppID/AppSecret 复制错了（注意全角字符/空格）② QQ 环境选错（沙箱/正式）③ 网络不通（服务器需能访问外网） |
| QQ 消息收不到 | ① 机器人未开启「接收所有消息」② 机器人没进群 ③ 群 openid 填错（过滤掉了）④ worker 未启用/未重启 ⑤ 发布状态未生效 |
| QQ 频繁掉线 | 机器人账号风控；建议专用小号、控制频率；我们的 worker 会自动重连（5 秒后） |
| 钉钉消息收不到 | ① `qyapi_chat_read` 权限未批 ② 群主未在群里授权 ③ chatId 填错/未填 ④ POLL_INTERVAL 未到 |
| 日报生成但内容空 | ① `AI_API_KEY` 未配置 ② 当天无消息 ③ AI 调用失败（看 worker 日志） |
| 登录被锁 429 | 连续失败 5 次锁定 10 分钟（防爆破），等一会儿或重启 web 解除 |
| 忘记密码 | 管理员：改 `configs/app.env` 的 `ADMIN_PASSWORD` 后重启 web（会自动重建种子） |
| worker 状态「已停止」 | 未启动 / 启动失败（看 `logs/` 或 `journalctl -u chat-monitor-*`） |
